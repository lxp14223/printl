 3.1 图像对齐
目的 ：消除扫描图像与模板之间的位置、旋转、缩放差异

┌─────────────┐                    ┌─────────────┐
│   模板图像   │                    │  扫描图像    │
│  (template) │                    │ (scanned)   │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       │    ┌──────────────────────┐      │
       └───→│  SIFT 特征点检测      │←─────┘
            │  - 检测关键点          │
            │  - 计算特征描述子      │
            └──────────┬───────────┘
                       ↓
            ┌──────────────────────┐
            │  FLANN 特征匹配       │
            │  - 找到对应的特征点对  │
            └──────────┬───────────┘
                       ↓
            ┌──────────────────────┐
            │  RANSAC 过滤          │
            │  - 剔除错误匹配       │
            │  - 保留内点           │
            └──────────┬───────────┘
                       ↓
            ┌──────────────────────┐
            │  计算仿射变换矩阵 M    │
            │  (只允许旋转/平移/缩放) │
            └──────────┬───────────┘
                       ↓
            ┌──────────────────────┐
            │  cv2.warpAffine()     │
            │  对齐扫描图像          │
            └──────────┬───────────┘
                       ↓
              对齐后的扫描图像

3.2 连通域分析
目的 ：将图像分成多个独立的检测区域，避免全局检测的误差
┌─────────────────────────────────────────────────────────────┐
│ 输入：模板灰度图                                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 二值化                                               │
│ - 自适应阈值二值化                                            │
│ - 白色=背景，黑色=内容                                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 2: 反转图像                                              │
│ - cv2.bitwise_not()                                          │
│ - 白色=内容（前景），黑色=背景                                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 3: 连通域检测                                            │
│ - cv2.connectedComponentsWithStats()                         │
│ - 返回：标签图、边界框、面积、中心点                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 4: 合并相邻连通域                                         │
│ - 判断条件1：包含关系（一个在另一个内部）                       │
│ - 判断条件2：距离近（边界距离 < min_distance）                 │
│ - 使用并查集算法合并                                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 输出：合并后的连通域列表                                        │
│ 每个连通域包含：边界框、面积、中心点                            │
└─────────────────────────────────────────────────────────────┘

3.3 单块缺陷检测
核心思想 ：对比模板和扫描图的前景区域，找出差异
┌─────────────────────────────────────────────────────────────┐
│ 输入：模板ROI (roi1)、扫描图ROI (roi2)                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 灰度转换                                              │
│ - cv2.cvtColor(BGR2GRAY)                                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 2: 二次对齐（可选）                                       │
│ - align_images_with_distortion()                             │
│ - 局部微调对齐                                                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 3: 高斯模糊降噪                                          │
│ - cv2.GaussianBlur(5x5)                                      │
│ - 减少噪声影响                                                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 4: 自适应二值化                                          │
│ - cv2.adaptiveThreshold()                                    │
│ - 根据局部区域计算阈值                                         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 5: 形态学预处理                                          │
│ - 膨胀：让线条变粗                        │
│ - 腐蚀：让线条变细                         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 6: 前景提取                                              │
│ - cv2.bitwise_not(二值图)                                    │
│ - 白色=印刷内容，黑色=背景                                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 7: 形态学闭运算                                          │
│ - cv2.morphologyEx(MORPH_CLOSE)                              │
│ - 填充小孔洞，连接断裂                                         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 8: 缺陷掩膜生成                                          │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ 漏印检测:                            │    │
│  │                                                      │    │
│  │   missing_mask = (template_fg > 0)                   │    │
│  │                  & (matched_fg == 0)                 │    │
│  │                                                      │    │
│  │   含义：模板有内容 AND 扫描图无内容 → 漏印            │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ 多印检测:                                │    │
│  │                                                      │    │
│  │   extra_mask = (signed_diff < -tolerance)           │    │
│  │               & (matched_fg > 0)                     │    │
│  │               & (template_fg == 0)                   │    │
│  │                                                      │    │
│  │   含义：扫描图有内容 AND 模板无内容 → 多印            │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 9: 缺陷掩膜清理                                          │
│ - 与前景区域做 AND 运算，确保在正确区域                         │
│ - 形态学开运算去除小噪点                                       │
│ - 形态学闭运算填充小孔洞                                       │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 10: 提取缺陷区域                                         │
│ - cv2.findContours() 找轮廓                                  │
│ - 过滤小面积 (area >= min_area)                               │
│ - 过滤低填充率 (fill_ratio >= threshold)                      │
│ - 计算边界框                                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 输出：缺陷区域列表                                            │
│ [{'rect': (x,y,w,h), 'area': 面积, 'type': '漏印/多印'}]      │
└─────────────────────────────────────────────────────────────┘

4.3 连通域合并算法
使用 并查集 算法合并相邻连通域：

┌──────────────┐     ┌──────────────┐
│   模板图像    │     │  扫描图像     │
│  (template)  │     │ (scanned)    │
└──────┬───────┘     └──────┬───────┘
       │                    │
       │                    ↓
       │            ┌──────────────┐
       │            │  去畸变处理   │
       │            │ (undistort)  │
       │            └──────┬───────┘
       │                    │
       └────────┬───────────┘
                ↓
        ┌──────────────┐
        │  SIFT对齐    │
        │ (仿射变换)   │
        └──────┬───────┘
                ↓
        ┌──────────────┐
        │  连通域分析   │
        │ (分块策略)   │
        └──────┬───────┘
                ↓
        ┌──────────────┐
        │  逐块检测     │
        │  ┌────────┐  │
        │  │灰度转换│  │
        │  │高斯模糊│  │
        │  │二值化  │  │
        │  │形态学  │  │
        │  │前景提取│  │
        │  │差分计算│  │
        │  │掩膜生成│  │
        │  │轮廓提取│  │
        │  └────────┘  │
        └──────┬───────┘
                ↓
        ┌──────────────┐
        │  坐标转换     │
        │ (ROI→原图)   │
        └──────┬───────┘
                ↓
        ┌──────────────┐
        │  NMS合并框   │
        └──────┬───────┘
                ↓
        ┌──────────────┐
        │  检测结果     │
        │ {            │
        │  defect_regions,│
        │  significant_diff,│
        │  missing,    │
        │  extra       │
        │ }            │
        └──────────────┘

图文检测的核心原理：

1. 图像对齐 ：SIFT特征匹配 + RANSAC + 仿射变换
2. 分块检测 ：连通域分析 → 逐块处理 → 坐标转换
3. 像素级差分 ：对比前景区域，找出漏印和多印
4. 形态学处理 ：腐蚀/膨胀/开运算/闭运算，去噪和填充
5. 结果后处理 ：NMS合并重叠框，过滤小面积缺陷
